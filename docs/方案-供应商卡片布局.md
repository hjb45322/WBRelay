# 方案 ・ 供应商卡片布局（操作区）

> 目标：把供应商卡片右侧「开关 + 4 个无边框文字按钮 + 测速结果」的一字排开，重做成
> 「状态组 ｜ 操作组（测速 / 编辑 / 复制 ｜ 删除）」的分区式操作区。
> 状态：已执行（2026-10-12）

---

## 一、现状问题（646px 宽面板实测）

```html
<div class="card-ops">
  <div class="switch" data-toggle="0"></div>
  <button class="ghost" data-ping="0">测速</button>
  <span class="ping-out" id="ping-0"></span>      <!-- min-width:50px，常驻空槽 -->
  <button class="ghost" data-edit="0">编辑</button>
  <button class="ghost" data-clone="0">复制</button>
  <button class="ghost" data-del="0">删除</button>
</div>
```

| # | 问题 | 证据（实测） |
|---|---|---|
| 1 | 操作区宽度失控：开关 + 4 按钮 + 空槽共 **340px**，而卡片只有 **554px**，右侧占掉六成 | `ops.w=340 / card.w=554` |
| 2 | 测速结果插在「测速」和「编辑」中间，槽位只有 50px：结果一出现（`测速中…` / `失败 HTTP 404`）就把后面 3 个按钮整体推走 | 空槽 `x=340..390`，`编辑` 起点随槽位内容漂移 |
| 3 | 4 个按钮同款同重（`ghost` 无边框、同灰色）：没有「常用 / 危险」的层级 | 4 个按钮 `color` 全部 = `--dim` `rgb(89,99,110)` |
| 4 | `class="ghost danger"` 被 `.ghost` 覆盖：**删除按钮根本不是红色** | 同上实测，`删除.color = --dim` |
| 5 | 开关（状态）夹在按钮（操作）堆里，没有分区线，视觉上一串等距灰字 | 截图：`⠿ 名称 … ●—— 测速　　编辑　复制　删除` |
| 6 | 窄宽度下操作区不换行，继续挤压名称 / URL / 模型 chips | `.card` 无 `flex-wrap`，`card-main` 被压到 197px |

## 二、设计约束

- 只改 `dashboard.html`（单文件、零依赖、Python 3.9 与 PyInstaller frozen 兼容）
- 复用既有令牌（`--panel2/--line/--accent2/--danger/--dim`）与既有组件语言，不引入新设计语言
- 不新增功能、不改接口、不改配置字段
- 既有选择器与绑定全部保留：`data-toggle` / `data-ping` / `data-edit` / `data-clone` / `data-del`、
  `#ping-<i>`、`.switch`、`.card-ops`（`bindCards()` 的拖拽排除逻辑依赖 `.card-ops`）

## 三、新布局

```
⠿  上游服务国内 [已启用][健康 100%]        ●——  │  [测速] 123 ms  │  [编辑][复制] │ [删除]
    http://127.0.0.1:8788/v1  responses  #1 优先级  超时 120s
    gpt-6*  codex-auto-review
```

| 区块 | 内容 | 样式 |
|---|---|---|
| `.ops-status` | `.switch`（状态）+ 竖分隔线 + `测速` 按钮 + `.ping-out` 固定槽 | 开关是「状态」，与操作用 1px `--line` 竖线分开 |
| `.ping-out` | 固定 `56px`、右对齐、`tabular-nums` | 成功 `.ok` 绿（`--accent2`）、失败 `.err` 红（`--danger`）、进行中灰；过长省略号 + `title` 放 HTTP 码 |
| `.ops-actions` | `编辑` `复制` ｜ `删除` | 按钮改为小号**有边框**按钮（`--panel2` 底 + `--line` 边，hover `--accent2`）；删除另起一组，红色 + hover 红边 |
| 竖分隔 | `.ops-sep`（1px × 20px，`--line`） | 状态 ｜ 操作 ｜ 危险操作 三段 |

修掉的既有 bug：`.ghost` 覆盖 `.danger` 导致删除按钮不是红色——新按钮类不再使用 `.ghost`，
并显式定义 `.card-ops button.danger{color:var(--danger)}`。

## 四、窄屏（≤980px）

```css
@media (max-width:980px){
  #pg-suppliers .card{flex-wrap:wrap}
  #pg-suppliers .card-ops{width:100%;justify-content:flex-end;border-top:1px solid var(--line);padding-top:10px}
}
```

操作区整行落到卡片下方、右对齐，上方一条分隔线；名称 / URL / chips 不再被挤压。
