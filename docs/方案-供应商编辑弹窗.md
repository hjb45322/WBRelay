# 方案 ・ 供应商编辑弹窗（描述与布局）

> 目标：把「编辑 / 添加供应商」弹窗从「7 个全宽字段一根长条」改为「连接 / 模型与运行」两组，
> 并把含糊或与实际行为不符的说明改准。
> 状态：已执行（2026-10-12）

---

## 一、现状问题（646px 面板实测）

弹窗：`560 × 682px`（`max-height:88vh`），单列 7 个字段，控件宽 **515px**。

| # | 问题 | 证据 |
|---|---|---|
| 1 | `.row2` 名义两列、实际 `flex-direction:column`：**超时 / 启用 是竖着排的**，白白多出一行高度 | `.row2{display:flex;gap:10px;flex-direction:column}`，实测两行 `y` 相差 57px |
| 2 | 必填字段没有任何标记：名称 / Base URL 全宽平铺，只有 Base URL 在保存时才报「必填」 | `#btn-ok` 里 `if(!f.base_url){ toast("Base URL 必填") }` |
| 3 | 模型清单的说明塞进 `<label>`：**标签 42 个字符**，与字段名混在一起 | 实测 `label` 文本长度 42 |
| 4 | API Key 说明与实际不符：写「掩码（sk-S\*\*\*1XNS）」，实际 `_mask_key()` 是「前 4 位 + 6 个星号 + 后 4 位」（如 `962e******08c2`）；也没说明「原样不动 = 保持原 Key」 | `wbrelay/settings.py:213 _mask_key` |
| 5 | 数字 / 下拉控件也占满 515px：超时只有一个 3 位数、启用只有 2 个选项，右边大片空白 | 实测 `inputW=515` |
| 6 | 7 个字段无分组，弹窗一屏铺满还接近要滚动 | `scrollHeight=680 / clientHeight=680` |
| 7 | 术语不统一：字段名用中文（名称 / 接口协议 / 超时），只有 `Base URL` 是纯英文 | 与 `docs/方案-文案与术语统一.md`「可见文案统一」不符 |

## 二、设计约束

- 只改 `dashboard.html`（单文件、零依赖、Python 3.9 与 PyInstaller frozen 兼容）
- 复用既有表单组件与令牌（`.field` / `.sub` / `.row2` / `--panel2` / `--line` / `--dim` / `--danger`）
- **不改任何表单 `id`**，不改 `openEdit()` / `openAdd()` / `collectForm()` / `#btn-ok` 的取值逻辑
- 不新增功能、不改接口、不改配置字段

## 三、新布局

```
编辑供应商
连接 ─────────────────────────
  名称                        [ 本地中转 ]
  接口地址 Base URL  [必填]   [ https://api.example.com/v1 ]
  API Key                     [ •••••••• ]
    回显为掩码；原样不动 = 保持原 Key，填新值即替换；新增供应商必填
  接口协议                    [ responses（Codex 直连，推荐） ]
    Codex 走 responses；仅当上游不支持 responses 时才选 chat/completions
模型与运行 ───────────────────
  模型清单                    [ gpt-*                  ]
    每行一个；支持 gpt-* 通配；留空 = 该供应商拉取到的模型全部接管
  [ 超时（秒） 120 ]   [ 启用 ▾ ]
                                  [ 取消 ]  [ 保存 ]
```

| 改动 | 内容 |
|---|---|
| 分组 | 新增 `.m-group` + `.m-group-title`（小号大写字距标题 + 上边框分隔）：**连接** / **模型与运行** |
| 两列 | `.row2` 改成**真两列**（`display:flex; gap:12px`，子项 `flex:1;min-width:0`，实测各 251px）；≤520px 时退回单列 |
| 必填 | Base URL 标签后加 `.req` 徽标「必填」（`--danger` 描边小胶囊） |
| 长标签 | 模型清单说明从 `<label>` 移到 `.sub` 说明行 |
| 粘贴按钮 | 名称 / 接口地址 / API Key 三个输入框后各加一个「粘贴」按钮（`.set-inline` 行内布局，按钮 `flex-shrink:0`，输入框 `flex:1`），点按整体写入该框 |
| 剪贴板来源 | 优先走**本机网关** `GET /api/clipboard`（`wbrelay/clipboard.py` 用 `ctypes` 只读 `CF_UNICODETEXT`），**不再触发浏览器「允许读取剪贴板」权限框**；网关旧版本返回 404 或非 Windows 时回退 `navigator.clipboard.readText()`；两者都不行则聚焦全选并提示按 Ctrl+V；剪贴板为空提示「剪贴板为空」 |
| 文案 | Base URL → **接口地址 Base URL**；API Key 说明改为「回显为掩码；原样不动 = 保持原 Key，填新值即替换；新增供应商必填」；接口协议补「Codex 走 responses；仅当上游不支持 responses 时才选 chat/completions」；模型清单说明改用 `.mono` 代码样式标 `gpt-*` |

**为什么不用浏览器剪贴板 API**：Chromium 读剪贴板要 `clipboard-read` 权限，第一次点「粘贴」会弹权限框；
而网关进程本来就跟浏览器在同一台机器上，直接读系统剪贴板既没有权限框，也不会因为窗口失焦读成空串。
接口只读、内容不进日志、`text` 截断到 64K 字符；非 Windows/读取失败回 `supported=false`，前端自动回退。

## 四、不改动 / 待确认

| 项 | 说明 |
|---|---|
| `#f-enabled` 用下拉而不是开关 | 与卡片上的 `.switch` 是同一语义的两种控件；改成开关要动 `collectForm()`，本轮不做 |
| 模型清单要不要也加「粘贴」 | 现在只有名称 / 接口地址 / API Key 三个框有；textarea 粘贴多行模型清单也可以加，待确认 |
| 弹窗内「测试连接」 | 卡片上有「测速」，弹窗里改完 Base URL / Key 无法先验证再保存；属新增功能，待确认 |
| 标题是否带供应商名 | 现为固定「编辑供应商」；可加 `· 名称`，避免同名误编辑，待确认 |

## 五、验收

- `python tests/check_dashboard_js.py` 全绿
- 弹窗实测（646px 面板）：`.row2` 两列（超时 / 启用同一行，各 251px）、模型清单 label 恢复为「模型清单」、
  Base URL 有「必填」徽标、弹窗 560×725（`scrollHeight == clientHeight`，1280×950 窗口下 88vh=836 不触发滚动）、无横向溢出
- 取消路径实测：点「取消」弹窗关闭、供应商 8 张卡片不变、未发起保存
- 剪贴板接口实测：`GET /api/clipboard` → 200 `{"supported": true}`（只核对了文本长度，未打印内容）；
  改后的线上一侧：后端进程未重启前该接口 404，前端自动回退浏览器 API（功能仍可用，但会弹一次权限）
- 粘贴按钮实测：3 枚按钮分别在对应输入框右侧同一行（`btn.x=531 > input.right=523`，输入框 457px / 按钮 49px），弹窗高度不变（725px）；点按后 toast 显示「已粘贴到本框（保存后生效）」、剪贴板为空时显示「剪贴板为空」
- 打开 / 取消 / 保存三条路径仍可用（`id` 未变）
- 红线：只在网关看板上做只读检查（不点保存），不写 `%APPDATA%\WBRelay\`，不碰 `~\.codex\config.toml`
