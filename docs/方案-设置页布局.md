# 方案 ・ 设置页布局

> 目标：把设置页从「单列长卡片堆叠」重构为「分区导航 + 设置卡片 + 常驻保存条」，
> 并为主项（分区）与子项（设置行）建立明确层级。
> 状态：待确认
> 术语（2026-10-11 起）：下文「反代」一律指上游服务，统一标准见 `docs/方案-文案与术语统一.md`。

---

## 一、现状问题（1440 宽实测）

| # | 问题 | 证据 |
|---|---|---|
| 1 | 7 张全宽卡片单列堆叠，无分区导航 | 内容高 2200px，需连续滚动 |
| 2 | 行宽约 1370px，标签与控件之间大片空白 | 控件贴在页面最右侧，扫读距离过远 |
| 3 | 布尔项是「说明下方一个复选框 + 开启」 | 与供应商卡片既有的 `.switch` 开关语言不一致 |
| 4 | 保存按钮埋在「系统」卡片中间 | 长页面里找不到入口，且无未保存提示 |
| 5 | 上游服务行内「保存」按钮被挤成两行 | 220px 控件列放不下 输入框+按钮 |
| 6 | 数字输入右对齐且无单位 | 端口 / 秒数 / 天数 难以区分 |
| 7 | 分区标题与行标题同为 13px/600、无缩进 | 主项子项无主次之分 |

## 二、设计约束

- 保持单文件、零依赖、Python 3.9 与 PyInstaller frozen 兼容（只改 `dashboard.html`）
- 复用现有设计令牌（`--panel/--panel2/--line/--accent2/--dim/--cool-fg`）与既有组件
  （`.switch`、`.badge`、`.data-cards`、`.sec-title`、`button.primary`），不引入新设计语言
- 不新增功能、不改接口、不改配置字段、不改核心语义
- 所有既有元素 `id` 必须保留（保存 / Keys / 备份 / 反代配置的 JS 绑定不变）

## 三、布局方案

```
设置  ┌ 说明文字 ─────────────────────────────────────────────┐   ← .sec-title（与其它页一致）
      ├──────────────┬────────────────────────────────────────┤
      │ 网络与路由   │  ┌ 主项：分区标题 + 一句说明 ──────┐   │
      │ 用量与统计   │  │   子项（缩进 16px）   [ 控件 ]  │   │   ← 行模型
      │ 安全与访问   │  │   子项（缩进 16px）   [ ●—— ]   │   │   ← 布尔项用 .switch
      │ 系统与集成   │  └────────────────────────────────┘   │
      │ 上游服务│  ┌ 下一张卡片 ─────────────────────┐   │
      │ 配置文件位置 │  └────────────────────────────────┘   │
      ├──────────────┴────────────────────────────────────────┤
      │ 状态文案                              [ 保存全部设置 ] │   ← 常驻保存条
```

- 左栏：`position:sticky` 分区导航（190px，6 项），点击滚动到分区，滚动时高亮当前分区
- 右栏：设置列 880px；卡片 = 主项标题带 + 若干子项行
- 保存条：`#pg-settings` 内滚动区之下常驻；右侧 `#btn-save-settings`，左侧状态文案
  （有未保存改动时变琥珀色 `--cool-fg`）
- 窄屏 `<980px`：导航变横向可滚动 chip；子项改为纵向堆叠、控件占满整行；
  布尔行（`.set-row.toggle`）保持「标签 + 开关」单行

## 四、主次层级（主项 / 子项）

| 层级 | 元素 | 字号 / 字重 | 其他 |
|---|---|---|---|
| 页面 | `.sec-title` | 15px / 600 | 与其它页签一致 |
| **主项** | `.set-card-head` | 14px / **700** | `--panel2` 底色标题带 + 下边框，横向 padding 18px |
| **子项** | `.set-row .meta .t` | 13px / 500 | 左缩进 34px（相对主项 +16px） |
| 说明 | `.set-card-head .d` / `.set-row .meta .d` | 12px / 400 | `--dim`，行高 1.5 |
| 控件 | `.set-row .ctl` | 13px | 右对齐到统一列（190–340px） |

- 主项靠「底色标题带 + 更大更重」区分，子项靠「缩进 + 降一档字号」区分
- 窄屏下子项缩进回收为 18px，主项/子项靠标题带区分

## 五、分区（沿用现有字段，仅重新归组）

| 分区 | 字段（原 id 不变） |
|---|---|
| 网络与路由 | `set-port` `set-timeout` `set-cool` `set-cool429` |
| 用量与统计 | `set-retention` `set-refresh` |
| 安全与访问 | `set-auth` `keys-wrap`/`keys-box`/`btn-add-key`/`btn-save-keys` `set-admin-token` `admin-token-field`/`set-admin-token-value`/`btn-copy-admin-token` |
| 系统与集成 | `set-codex-provider` `set-autostart` `set-theme` |
| 上游服务 | `set-upstream-enabled` `set-upstream-dir`/`btn-save-upstream-dir`/`upstream-dir-hint` `set-upstream-autostart` `set-upstream-watchdog` `set-upstream-autologin` `set-upstream-password`/`btn-save-upstream-conf` `upstream-reg-hint` `upstream-port-badge` |
| 配置文件位置 | 只读展示：`path-data-dir` `path-settings` `path-usage` `path-profiles` `path-models-cache` `path-log` `path-ide-backups`（数据来自 `/api/settings` 的 `paths` / `path_exists`） |

> `set-autostart`（开机自启**网关**）与 `set-upstream-autostart`（开机自启 **上游服务**）
> 是两个不同字段，文案中显式区分，避免歧义。

## 七、附带修正（同页内的小 bug）

| 位置 | 问题 | 处理 |
|---|---|---|
| `set-theme` | 载入时从不回显当前主题，永远显示第一项「浅色」 | `loadSettings` 内回显 `THEME` |
| Keys 输入框 | 背景用 `--panel`，与其它设置项输入框不一致 | 统一为 `--panel2` |
| 上游服务行「保存」 | 被挤成两行 | 改为同行 `flex` 且 `white-space:nowrap` |
| 上游端口徽标 | 「（自动检测）」恒为灰色中性徽标，成功态与兜底态无法区分 | 检测到反代入口（`entry_found`）→ `.badge.vis` 绿色；退回默认 8788 → `.badge.neutral` 灰色，文案改「（默认值，未检测到入口）」 |
