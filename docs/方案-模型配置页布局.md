# 方案 ・ 模型配置页布局

> 目标：把「模型配置」页从「一行内塞满标题 + 主操作 + 长说明 + 统计括号串」改为
> 「标题 / IDE 卡片 / 带边框的拉取容器 / 带边框的分组容器（内为分组独立卡片）」四段式，
> 消除换行错位、扫读困难与分组边界不清。
> 状态：已执行（2026-10-12）
> 术语遵守 `docs/方案-文案与术语统一.md`（本轮只改布局，不动文案语义）。

---

## 一、现状问题

页头只有**一个** `.sec-title` 弹性行，装进了四类内容：

```html
<div class="sec-title">          <!-- display:flex; flex-wrap:wrap; gap:10px -->
  模型配置
  <button id="btn-refresh-models" class="primary">…重新拉取</button>
  <span class="hint">拉取 = ①获取上游模型 ②更新模型档案库；档位优先用上游的，没有则用档案库补全 · 启停按模型名全局联动 · 倍率以上游返回为准</span>
  <em id="models-meta"></em>      <!-- margin-left:auto -->
</div>
```

| # | 问题 | 证据 |
|---|---|---|
| 1 | 标题、主操作按钮、说明、统计挤在同一条弹性行里，四个角色的层级完全相同 | 上面 4 个元素同级排列，只有 15px/12px 的区别 |
| 2 | 说明长（约 60 字），窄屏或长统计串下会在行尾折成 2–3 行，且断点位置随机 | `.sec-title` 是 `flex-wrap:wrap`，说明本身也是一个不可拆的 flex 项 |
| 3 | 统计串 `（上次拉取 … · 33 个模型 · …）` 是一整段括号文字，`margin-left:auto` 把它推到最右 | 视觉上「右对齐的一坨字」，没有标签/数值的对比 |
| 4 | 每个上游分组各自一张表，但分组之间没有共同容器，分不清列表边界 | 分组头 `div.mg-head` 与表在滚动区里裸排 |

## 二、设计约束

- 只改 `dashboard.html`（单文件、零依赖、Python 3.9 与 PyInstaller frozen 兼容）
- 复用既有令牌与组件（`--panel/--line/--dim/--fg`、`button.primary`、`.cards-frame`、`.set-card`），不引入新设计语言
- 不新增功能、不改接口、不改配置字段、不改核心语义
- `id` 全部保留：`#btn-refresh-models`、`#models-meta`、`#ides-strip`、`#models-box`（刷新按钮 / `renderModels` 的 JS 绑定不变）

## 三、布局方案

```
模型配置                                                                     ← 页面标题
┌ IDE 客户端接管（.set-card） ───────────────────────────────────────────┐
│ 把本机网关地址与模型清单写进这些客户端…        [Codex] [OpenCode] [DSH] │
└──────────────────────────────────────────────────────────────────────┘
┌ 拉取容器（.cards-frame.ph-box） ───────────────────────────────────────┐
│ [ ↻ 重新拉取 ]  拉取 = ①获取上游模型 ②更新模型档案库 · 档位优先用上游的， │
│                 没有则用档案库补全 · 启停按模型名全局联动 · 倍率以上游返回为准 │
│ [上次拉取 …] [模型 33 个] [上游 4 个] [Key 配置 8 个] [模型档案库 480 个] │
│ [自动同步 458 个已知模型]                                               │
└──────────────────────────────────────────────────────────────────────┘
┌ 模型分组容器（.cards-frame#models-box：浅灰托底 + 固定边框 + 内部滚动） ─┐
│ ┌ 分组卡片 .mg-sec（白底 + 1px 边框 + 圆角 + 阴影） ─────────────────┐ │
│ │ ▾ 上游服务国内 …  [全启用][全停用]                              │ │
│ │    模型表（可折叠，表格不再自带外框）                              │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│ ┌ 下一张分组卡片 ─────────────────────────────────────────────────┐ │
│ └──────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

| 段 | 元素 | 样式 |
|---|---|---|
| 标题 | `.ph-title` | 15px/600，独占一行 |
| IDE 卡片 | `#ides-group.set-card` | 复用设置页卡片（标题带 + 内容区） |
| 拉取容器 | `.cards-frame.ph-box` | 2px 边框 + 12px 圆角 + `--panel` 底色，与分组容器同款 |
| ├ 主操作 + 说明 | `.ph-actions` + `button#btn-refresh-models` + `.ph-desc` | 按钮左对齐；说明 12px `--dim` 紧随按钮，宽带同行、窄带落到按钮下一行 |
| └ 统计 | `#models-meta.ph-stats` + `.mm-chip` | 每项独立胶囊：标签 11px `--dim` + 数值 12px/600 `--fg`（`tabular-nums`） |
| 分组容器 | `#models-box.scrollbox.cards-frame` | 所有上游分组共用一张边框；**托底改为 `--panel2`**（浅灰），内容在框内滚动（与供应商页 `#cards-scroll` 同款） |
| 分组卡片 | `.mg-sec` | 每张卡片：`--panel` 白底 + 1px `--line` 边框 + 10px 圆角 + `0 1px 3px #0000001a` 阴影；`.mg-head` 底部 1px 分隔线（折叠时透明，避免双线） |

- 说明按**规则片段**拆成 4 个 `<span>`（片段内 `white-space:nowrap`），分隔符 `·` 绑在前一个片段尾部：
  换行只会发生在规则之间，不会把半句拆开、也不会出现行首孤零的「·」
- 统计串不再用括号包一坨文字，改为**一词一值**的胶囊；胶囊可换行
- 阅读顺序：这是哪一页 → 接管了哪些客户端 → 拉取按钮做什么、规则是什么、当前数据 → 分组模型清单

## 四、统计项映射（字段不变）

| 胶囊标签 | 数值来源 | 原文案 |
|---|---|---|
| 上次拉取 | `v.fetched_at`（`T` 换成空格） | `上次拉取 <ISO>` |
| 模型 | `v.model_count` + 「个」 | `<n> 个模型` |
| 上游 | `v.groups.length`（无 groups 时退回 `suppliers` 键数）+ 「个」 | `共 <n> 个上游` |
| Key 配置 | `Object.keys(v.suppliers).length` + 「个」 | `<n> 个 Key 配置` |
| 模型档案库 | `v.profiles.count` + 「个」 | `模型档案库 <n> 个` |
| 自动同步 | `v.profiles.auto.known` + 「个已知模型」；无 `synced_at` 时显示「待首次拉取」 | `自动同步 <n> 个已知模型` |

## 五、窄屏与主题

| 宽度 | 表现 |
|---|---|
| 1440 | 标题 / IDE 卡片 / 拉取容器（按钮+说明同行、统计一行）/ 分组容器占满剩余高度、内部滚动 |
| 390 | 标题 / IDE 卡片 / 拉取容器（按钮、说明 3 行、统计 3 行）/ 分组容器 |

- **窄屏关键修正**：`@media (max-width:980px)` 下 `#pg-models` 整体滚动、`#models-box` 取消内部滚动
  （否则固定的标题+卡片+拉取容器会把列表区压到只剩几十像素）
- 明暗主题均复用既有令牌，不新增颜色

## 六、验收

- 1440×900 与 390×844 两档截图（明暗两主题）：`models-{1440,390}-{light,dark}.png`
- `python tests/check_dashboard_js.py` 全绿
