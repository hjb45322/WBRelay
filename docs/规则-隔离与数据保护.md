## 二、写入白名单

本项目的写入范围**仅限**：

1. `<项目目录>\`（本项目目录）
2. `<工作根目录>\_wbrelay-snap\`（快照目录，仓库外）
3. 显式通过 `--data-dir` 指定的临时目录
4. `%LOCALAPPDATA%\Temp\` 下的临时文件

**除此之外一律不得写入。**

## 三、启动规则

### 3.1 开发与测试一律使用完整参数

```
python relay.py --data-dir <临时目录> --no-ide-inject --port <非 8789 端口>
```

禁止使用裸启动（不带 `--data-dir`）进行任何测试。

### 3.2 端口规则

| 端口 | 用途 |
|---|---|
| 8789 | 在用实例，**禁止占用** |
| 18789 | 本项目默认开发端口 |
| 18899 | 只读预览端口 |

### 3.3 数据目录规则

- 本项目默认数据目录：`%APPDATA%\WBRelay\`（2026-10-11 接管，原 `WBRelay-OSS`）
- 解析优先级：`--data-dir` > `WBRELAY_DATA_DIR` > 默认值
- 若解析结果落在历史/归档目录（`%APPDATA%\WBRelay-OSS`、`%APPDATA%\WBRelay-legacy-*`），
  必须拒绝启动，除非显式传入 `--allow-legacy-data`

### 3.4 网关重启规则（值守进程）

| 项 | 规则 |
|---|---|
| 为什么 | 网关是本机 Codex 的上游：**在会话内重启时，调用方会话会随网关一起中断**，重启动作若留在会话里执行就再也做不完，会话也回不来——所以「停 → 起 → 等就绪」必须交给会话之外的值守进程 |
| 允许 | 重启在用网关（含协作方在会话内直接重启）；2026-10-12 起，见 `AGENTS.md` R7 |
| 唯一入口 | `python tools/restart-gateway.py [--port 8789]`：值守进程执行「停旧 → 等端口释放 → 用原命令行拉起 → 轮询就绪」，脱离调用方会话 |
| 禁止 | 手工 `taskkill`、自写 `Popen`、托盘退出后再手工启动——任何绕过值守进程的重启方式 |
| 进程识别 | 只操作「命令行/可执行路径 + `/api/state` 语义」同时对得上、且属于本项目入口的进程；认不出来一律拒绝。**没有 `--force`**（第三轮删除）；隐藏 worker 只能由父进程用一次性交接文件拉起，结束进程前独立复核 PID / 可执行路径 / 命令行 / 启动时间 / 端口监听 |
| 结束后代 | 只逐个结束已确认归 WBRelay 的 PID（`taskkill /PID <pid>`，**不带 `/T`**）；出现任何不明后代就停止并报告 |
| 启动命令 | 只允许本仓库 `relay.py` 的 Python 入口或本仓库内的 `WBRelay.exe`；**没有 `--cmd` / `--move`** |
| 就绪判据 | `/api/state` 返回 JSON 才算就绪（实测约 4.5s）；未就绪要在值守日志里查原因 |
| 日志 | `%LOCALAPPDATA%\Temp\wbrelay-restart-<时间戳>.log` |
| 不碰 | Codex / 上游服务 / CC Switch 等外部进程（R5 不变） |

## 四、测试规则

1. 所有测试必须指定独立 `--data-dir`
2. 所有测试必须带 `--no-ide-inject`
3. 测试前后必须跑隔离断言（见第六节）
4. 禁止编写依赖真实外部服务的测试；上游一律用 mock（18788 / 18789）
5. 禁止在测试中读写 P1–P6

## 五、敏感信息规则

| 规则 | 说明 |
|---|---|
| 密钥不落盘 | `wb_password` 等账号密码字段不允许写入配置文件 |
| 密钥不入库 | 任何真实 Key / 域名 / 内部路径不得进入 git |
| 快照含密钥 | 快照目录必须在任何仓库之外，永不打包分发 |
| 截图脱敏 | 涉及真实供应商名、域名、Key 的截图不得入库 |
| 日志降级 | 日志中的 Key 一律掩码；错误信息截断 |

## 六、隔离断言（每阶段必跑）

**输入**：阶段开始前采集的哈希清单
**输出**：逐项 PASS / FAIL

采集内容：

- P1 全量文件：路径 + size + mtime + SHA256
- P2 / P3：同上
- P4：SHA256

判定：

| 情况 | 结果 |
|---|---|
| 文件缺失 / 新增 | FAIL |
| 内容变化（size 或 sha256 不同） | FAIL |
| **内容一致、仅 mtime 变化** | **WARN**（外部程序整文件重写，如 Codex 自身、在用网关重启） |
| 追加型文件变大但历史前缀一致 | 合法增长，仅提示 |

需要把 mtime 变化也当失败时，加 --strict-mtime。

> 说明：%APPDATA%\WBRelay 与 ~\.codex 会被**在用网关自身**和 **Codex 桌面应用**
> 定期整文件重写。遇到 WARN 先查在用网关的 wb.log 与进程启动时间，再判断是否为本项目所致。
