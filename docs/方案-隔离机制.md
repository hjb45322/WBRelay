# 方案 ・ 隔离机制

> 对应里程碑 M1。目标：让本项目在**任何参数组合下**都不可能读写到在用环境。
> 状态：**已实现（M1，2026-10-11）**
> 修订（2026-10-11 身份接管）：默认数据目录名由 `WBRelay-OSS` 改为 `WBRelay`，下文涉及该目录名的描述按此读。

---

## 一、设计原则

1. **默认安全**：不带任何参数时，也应该碰不到在用的 WBRelay 数据与 Codex 配置
2. **单一收口**：所有可能写外部路径的行为，必须经过同一个判断函数
3. **可证明**：每个开关都有对应的自动化断言，不依赖人工确认
4. **不改变终端用户行为**：除数据目录名与 IDE 接管默认值外，功能表现与重构前一致

---

## 二、数据目录解析

### 2.1 时机问题（关键）

现状 `relay.py:53` 在**模块导入时**就计算了 `DATA`，同一批常量（`SETTINGS_PATH` / `USAGE_PATH` / `MODELS_CACHE_PATH` / `PROFILES_PATH` / `BACKUP_DIR` / `LOG_PATH`）紧随其后。

若把 `--data-dir` 的解析放在 `main()` 里，上面这些常量**早已定死**，参数不生效。

**解决**：在模块顶部、常量定义之前完成解析。

```
# 伪代码（位于所有路径常量之前）
def _resolve_data_dir():
    cli = _argv_value("--data-dir")
    if cli: return _normalize(cli)
    env = os.environ.get("WBRELAY_DATA_DIR")
    if env: return _normalize(env)
    return os.path.join(os.environ.get("APPDATA") or os.path.expanduser("~"), APP_DIR_NAME)

DATA = _resolve_data_dir()
```

### 2.2 优先级

| 顺序 | 来源 | 优先级 |
|---|---|---|
| 1 | 命令行 `--data-dir <path>` | 最高 |
| 2 | 环境变量 `WBRELAY_DATA_DIR` | 中 |
| 3 | 默认 `%APPDATA%\WBRelay-OSS\` | 最低 |

**`settings.json` 不能参与决定数据目录**：settings 本身就在数据目录内，存在循环依赖。

### 2.3 边界检查

| 检查 | 行为 |
|---|---|
| 非绝对路径 | 报错退出 |
| 无法创建 / 无写权限 | 报错退出 |
| 解析结果等于 `%APPDATA%\WBRelay`（在用数据） | **拒绝启动**，除非显式传 `--allow-legacy-data` |
| 解析结果落在原项目目录内 | 报错退出 |

第三条是这次重构最重要的安全阀：默认情况下，本项目**不可能**打开在用的数据目录。

### 2.4 默认目录

| 项 | 值 |
|---|---|
| 常量名 | `APP_DIR_NAME` |
| 当前值 | `WBRelay-OSS` |
| 位置 | 单一来源，仅在一处定义 |
| 说明 | 正式命名确定后只改这一处 |

## 三、IDE 写入开关（`--no-ide-inject`）

### 3.1 现状：四条写入路径

| # | 位置 | 行为 |
|---|---|---|
| 1 | `relay.py:3931` `ides_backup_and_inject(port)` | 启动时备份并改写 IDE 配置 |
| 2 | `relay.py:2858` `POST /api/codex/sync` | 写 catalog + 杀并重启 Codex |
| 3 | `relay.py:2918` `/api/ides/{id}/restart` | 同上（看板「重启」按钮） |
| 4 | `relay.py:3026` 模型刷新路径 | `sync_all_ide_catalogs()` 重写 catalog |

后三条**目前完全不判断 `ides.enabled`**，只取决于有没有被调用。

### 3.2 设计：统一收口

新增判断函数：

```
def ide_write_allowed(ide_id):
    if side_effects_disabled():      # --no-ide-inject
        return False
    if readonly_mode():
        return False
    return ide_enabled(ide_id)       # 现有开关，默认改为 False
```

**所有**以下动作必须经过它：

| 动作 | 说明 |
|---|---|
| `backup` | 写 `ide_backups/` |
| `inject` | 改写 IDE 配置文件 |
| `sync_catalog` | 写模型清单文件 |
| `restart` | 杀并重启外部进程 |
| **`restore`** | 回滚 IDE 配置 |

> `restore` 也必须经过：若某数据目录里残留着旧的 `ide_backups/*.json`，退出时的 restore 会直接改写外部配置 —— 这条容易被漏掉。

### 3.3 被拦截时的表现

| 场景 | 表现 |
|---|---|
| 启动 | 日志：`IDE 接管已禁用（--no-ide-inject）` |
| 管理 API | HTTP 403，`{"error":{"message":"IDE 接管已禁用"}}` |
| 看板 | 对应卡片置灰并显示原因 |

### 3.4 默认值调整

`relay.py:1552` 的回落默认值 `True` → `False`。
只影响**未显式配置**的新用户；已显式写 `ides.codex.enabled` 的配置不受影响。

## 四、只读模式（`--readonly`）

### 4.1 目标

提供一个「只看不改」的运行模式，用于看板验证与演示。

### 4.2 范围

| 项 | 普通模式 | 只读模式 |
|---|---|---|
| `GET /api/*` | 允许 | 允许 |
| `POST /api/*` | 允许 | **403** |
| `GET /` 看板 | 允许 | 允许 |
| 用量写入 `usage.jsonl` | 写入 | **不写** |
| 定时清理线程 `_retention_loop` | 运行 | **不启动** |
| 上游守护线程 `_watchdog_loop` | 运行 | **不启动** |
| 开机自启写注册表 | 按设置 | **禁止** |
| IDE 接管与写入 | 按开关 | **禁止** |
| `/v1/*` 转发 | 允许 | 允许（不记录用量） |

> 说明：现有 `tests/preview_readonly_server.py` 复用同一个 Handler，其文件头声称"不写任何数据"，但实际上点看板的保存按钮仍会写真实配置。只读模式正是为修正这个语义落差而设。

## 五、参数组合行为矩阵

| 参数组合 | 数据写入 | IDE 写入 | 后台线程 | 适用场景 |
|---|---|---|---|---|
| 无参数 | `%APPDATA%\WBRelay-OSS\` | 默认禁止 | 开 | 终端用户 |
| `--data-dir X` | X | 默认禁止 | 开 | 手工调试 |
| `--data-dir X --no-ide-inject` | X | 禁止 | 开 | **开发与测试强制** |
| `--data-dir X --no-ide-inject --readonly` | 禁止 | 禁止 | 关 | 看板预览 / 演示 |

## 七、兼容性说明

- 终端用户可见的变化只有两点：默认数据目录名、IDE 接管默认关闭
- 命令行参数为**新增**，不影响既有用法
- `--port` 行为保持不变
- 原项目的 `start.bat` / 打包参数在本项目继续可用（`relay.py` 保留为入口，见 `docs/方案-架构拆分.md`）

## 八、已实现的命令行开关（M1）

| 开关 | 环境变量 | 作用 |
|---|---|---|
| `--data-dir <path>` | `WBRELAY_DATA_DIR` | 覆盖数据目录（必须在路径常量之前解析） |
| `--allow-legacy-data` | — | 显式放行旧版数据目录（默认拒绝） |
| `--no-ide-inject` | `WBRELAY_NO_IDE_INJECT=1` | 禁止一切 IDE 配置写入与进程操作 |
| `--readonly` | `WBRELAY_READONLY=1` | 只读模式 |
| `--headless` | `WBRELAY_HEADLESS=1` | 不创建窗口与托盘（自动化验证 / CI） |
| `--port <n>` | — | 监听端口 |

实现位置：

| 机制 | 位置 |
|---|---|
| 数据目录解析 + 两个安全阀 | `relay.py` 常量区（`APP_DIR_NAME` / `_resolve_data_dir`） |
| 统一 IDE 写入判定 | `ide_write_allowed()` / `ide_inject_disabled_reason()` |
| 只读写入兜底 | `_log` / `save_settings` / `save_profiles` / `save_models_cache` / `enforce_usage_retention` 各自早退 |
| 管理接口门禁 | `do_POST` 顶部 READONLY 判定 |
| 后台线程门禁 | `main()` 中 watchdog / retention / 自启动注册 |

> 只读模式采用「写操作原语级兜底」：即使将来新增调用路径，也写不进任何文件。

| 用例 | 结果 |
|---|---|
| `--data-dir` 指向旧版数据目录 | 拒绝启动，exit 1 |
| 加 `--allow-legacy-data` | 放行 |
| 默认数据目录 | `%APPDATA%\WBRelay-OSS` |
| `POST /api/codex/sync`（带 `--no-ide-inject`） | 403 |
| `POST /api/ides/{id}/restart`、`/toggle` | 403 |
| `--readonly` 下所有 `POST /api/*` | 403 |
| `--readonly` 数据目录文件数 | **0** |
